# ⚔️ 新武士道列傳 RPG (Shin Bushido Retsuden RPG)

**王道和風三人小隊 × 傳統回合指令制 JRPG × 全彩 2D 像素地圖與和風配樂 (Svelte 5 + TypeScript + Canvas 2D)**

👉 **線上立即遊玩 (GitHub Pages)**：[https://rexchien.github.io/samurai-idle-rpg/](https://rexchien.github.io/samurai-idle-rpg/)

---

## ✨ 核心特色

- **🕹️ 正統 90 年代黃金期和風回合指令制戰鬥（Turn-Based Command Battle）**：
  - 徹底摒棄放置掛機玩法，採用致敬《武士道列傳》的**橫向回合指令制戰鬥舞台**與**皇家深藍金框指令選單**。
  - **六大戰術指令**：
    1. `⚔️ 拔刀連斬`：主角與兩名夥伴協同連攜追擊，回復氣力 (SP) 與怒氣 (POW)。
    2. `📜 劍技・秘術`：消耗氣力 SP 施展《居合・拔刀斬》、《秘劍・燕返》、《紅蓮・火車切》、巫女《神樂・回天祈禱（全隊補血）》、伊賀忍法《鳴神破甲（全體落雷降防）》與《二天一流・天地雙斬》。
    3. `🔥 天覇絕刀（POW 100% 怒氣超奧義）`：經典怒氣槽滿載時解鎖超必殺技《二天一流・天覇封神斬》，對敵方全體造成毀滅性神聖暴擊！
    4. `🛡️ 納刀見切`：全隊進入明鏡止水守勢，本回合減傷 65% 並大幅回復 SP 與怒氣。
    5. `🍡 行囊道具`：使用花見三色糰子、宇治極品抹茶、般若湯銘酒、秘傳萬金丹。
    6. `⚡ 全員總攻（智慧戰術委任 / 空白鍵）`：依據戰況自動施展補血、超奧義或範圍劍技。
- **👥 三人同行小隊系統（地圖排隊跟隨 & 協同作戰）**：
  - **主角（二天劍豪）**、**神無月 楓（破邪巫女）**、**影縫 疾風（伊賀疾風忍）** 三人小隊於全彩地圖上排隊跟隨行走，並在回合戰中並肩作戰。
- **🗺️ 全彩高細節像素開放世界與 JRPG 城鎮宿屋對話框**：
  - 涵蓋**京都・洛中城下町**（滿開櫻花、鴨川錦鯉、朱紅太鼓橋、花見茶屋宿屋、柳生道場、國友鍛冶屋、出雲大社）、**鞍馬山翠竹林**、**東海道紅楓驛道**、**赤富士戰場**、**日光東照神域**與**常世彼岸花海**。
  - 點擊城鎮 NPC 展開**經典 JRPG 皇家藍底金框頭像對話視窗**，可於茶屋宿屋休息全回復、採買糰子與銘酒、或與道場門生切磋。
- **🎵 多聲道傳統和風背景音樂 (BGM) 合成引擎**：
  - Web Audio API 即時合成尺八吹管、三味線／古箏撥弦、大太鼓與神樂鈴，內建四首和風曲目（《洛中花見・都之春》、《武士道列傳・疾風街道》、《鞍馬靈峰・神域幽玄》、《五輪拔刀・百鬼夜行》）。

## 🚀 開發與建置

```bash
# 安裝依賴
npm install

# 執行單元測試 (Vitest)
npm test

# 啟動開發伺服器
npm run dev

# 建置單一 HTML 離線可攜版 (輸出至 dist/index.html)
npm run build
```
