# 🗡️《無雙劍心：武士之刃》（Samurai Blade: Idle RPG）

一款專為 GitHub Pages 打造的純前端**日式戰國名刀放置 RPG 網頁遊戲**。結合江戶與戰國浪人修羅之路、豐富的日本名刀歷史考證、踏鞴鍛造、砥石研磨與流派心法！

## 🌸 遊戲特色

1. **戰國江戶歷史名刀收錄**：
   - 凡鐵：無銘竹光、鍛鐵白木刀、備前古刃
   - 業物：和泉守兼定（土方歲三）、加州清光（沖田總司）、陸奧守吉行（坂本龍馬）、堀川國廣
   - 良業物：同田貫正國（天覽兜割）、長曾彌虎徹（近藤勇）、備前長船長光
   - 大業物：菊一文字則宗、千子村正（德川妖刀）、雷切（立花道雪）、燭台切光忠（伊達政宗）
   - 最上大業物（天下五劍）：童子切安綱（源賴光斬鬼）、三日月宗近、大典太光世、鬼丸國綱、數珠丸恆次
   - 神話妖刀：妙法村正・真打、天羽羽斬（十拳劍）、天叢雲劍（草薙劍）
2. **七大歷史戰役關卡**：
   - 第 1 幕：尾張・荒野竹林（守門狂僧・豪圓）
   - 第 2 幕：伏見・千本鳥居（甲賀上忍・夜叉丸）
   - 第 3 幕：京都・三條夜街（示現流狂徒・大石）
   - 第 4 幕：越後・雪嶺古關（霜雪刀聖・長尾景連）
   - 第 5 幕：本能寺・紅蓮業火（第六天魔王・信長殘影）
   - 第 6 幕：關原・修羅血河（赤鬼修羅・井伊殘念）
   - 第 7 幕：江戶城・天守極頂（天下無雙・宮本武藏之魂）
3. **踏鞴鍛造與研磨強化系統**：
   - 收集擊敵獲得的【玉鋼】與【金小判】，委任刀匠進行鍛刀。
   - 使用【荒砥石】、【中砥石】與【天然仕上砥石】研磨刀身，大幅激發攻擊力與鋒利度。
   - 熔煉多餘名刀，分解回收玉鋼素材。
4. **武士三大流派天賦**：
   - **新陰流・活人劍**：專精神速拔刀、極致會心率與燕返暴擊傷害。
   - **示現流・一之太刀**：專精霸道攻擊力加成與破甲穿透。
   - **天然理心流・誠之意**：專精氣血上限加成與高額防禦護體。
5. **純 Web Audio API 物理合成音效**：
   - 零依賴任何外部音檔，秒開不卡頓，純物理頻率合成拔刀斬風聲、清脆格擋、暴擊重斬與鍛造鐵砧敲打聲！
6. **離線掛機收益與全端響應式支援**：
   - 手機、平板與電腦全設備適配。
   - 關閉網頁自動離線歷練，重新打開獲得豐厚離線掛機收益。
   - 支援 LocalStorage 自動存檔、代碼匯出與匯入。

## 🚀 GitHub Pages 部署指南

本專案為純靜態單頁應用（SPA），無需 Node.js 編譯或伺服器後端，直接上傳至 GitHub 倉庫即可透過 GitHub Pages 免費發布：

1. 將本專案代碼推送至 GitHub 倉庫（例如 `RexChien/samurai-idle-rpg`）。
2. 進入倉庫頁面，點擊 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，目錄選擇 `/(root)`，點擊 **Save**。
5. 等待 1~2 分鐘，即可透過 `https://<您的帳號>.github.io/<倉庫名稱>/` 直接開啟遊戲遊玩！
