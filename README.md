# ⚔️ 天明武士・五輪百鬼譚 (Samurai Tenmei 7 RPG)

**Svelte 5 + TypeScript + Canvas 2D 3頭身像素風開放世界 × 暗黑刷寶武士 RPG**

👉 **線上立即遊玩 (GitHub Pages)**：[https://rexchien.github.io/samurai-idle-rpg/](https://rexchien.github.io/samurai-idle-rpg/)

---

## ✨ 核心特色

- **🎨 3頭身像素風（Chibi 16×24 Pixel Art）角色與 NPC**：
  - 全角色與 NPC（劍豪羽織、般若武者、旗本大將、破邪巫女、柳生嚴信、神無月楓、國友鐵齋、茶屋小町，以及貪吃赤面鬼、鞍馬小天狗、稻荷白狐等妖怪）皆以原生 3 頭身像素網格繪製，支援行走步伐動畫與對話肖像。
- **🏮 天明七年（1787 AD）溫馨市井與熱血冒險世界觀**：
  - 取材自日本公開領域歷史（天明七年、寬政改革、宮本武藏《五輪書》、《百鬼夜行》），100% 原創人物與劇情，嚴格迴避任何第三方商業 IP。
  - 外界雖因火山灰與百鬼夜行而有些慌亂，但京都洛中城下町提燈高掛、茶屋糰子飄香，充滿輕鬆溫暖的人情味。
- **🗺️ Canvas 2D 開放世界地圖探索**：
  - 支援 WASD / 方向鍵、虛擬搖桿、點擊地板移動與任務一鍵導航，漫步於京都洛中城下町與八大討伐秘境，與 NPC 近距離互動或觸發遭遇戰。
- **🗡️ 暗黑破壞神（Diablo）六階神兵詞綴系統**：
  - 六大部位（主武器、副手、兜鍪、胴丸、具足、御守）× 六階品質（凡品、名物、業物、大業物、傳奇、太古神兵），附帶隨機詞綴、傳奇特效、國友鐵齋鍛造強化與重鑄。
- **⚙️ 任務解鎖漸進式自動體系（Tier 0 ～ Tier 4）**：
  - 初始為親手拔刀（點擊、按住連斬、空白鍵無障礙友善操作），隨主線任務推進逐步解鎖「劍心初醒（1.2s）」、「二天連斬（0.65s）」、「式神同遊（0.5s）」至「無念無想（0.35s）」。
- **📜 30 章史詩主線 + 20 篇城下町輕鬆支線 + 無限街坊委託**：
  - 涵蓋試刀護糧、花見糰子、尋回三花貓、箱根溫泉、隅田川花火至常世百鬼夜宴。
- **☯️ 宮本武藏《五輪書》架勢相剋 × 天下第一武道大會（PvP 切磋碼） × 千層試煉秘境**：
  - 地、水、火、風、空五輪相剋，支援 0 伺服器成本的 `DUEL_` 跨玩家切磋碼分享對決與 1000 層無間試煉。

## 🏗️ 專案架構

- `src/engine/`：
  - `GameStore.svelte.ts`：Svelte 5 Runes (`$state`) 響應式核心遊戲狀態機、戰鬥迴圈、裝備掉落與任務推進
  - `WorldMapEngine.ts`：Canvas 2D 開放世界地圖渲染器、3頭身角色行走動畫、NPC 互動與視野跟隨
  - `pixelSprites.ts`：16×24 原生 3 頭身像素點陣圖庫與 Canvas 繪製工具
  - `AudioEngine.ts`：Web Audio API 程序化三味線／尺八和風音效合成器
- `src/data/`：天明七年世界觀、流派、六階神兵詞綴、五輪架勢、30 章主線＋20 篇支線、武道大會與成就資料
- `src/components/`：Svelte 5 模組化介面組件（開放世界畫布、神兵鍛造、任務日誌、武道深淵、樂市茶屋、創角與成就橫幅）
- `test/tenmei.test.ts`：Vitest 自動化單元測試套件

## 🚀 開發與建置

```bash
# 安裝依賴
npm install

# 執行單元測試 (Vitest)
npm test

# 啟動開發伺服器
npm run dev

# 建置單一 HTML 離線可攜版 (輸出至 dist/index.html)
npm run build
```
